Afaq Notes - نشر على GitHub Pages (نسخة واحدة: تثبيت + بدون نت + PDF)
================================================================
ارفع كل محتويات الفولدر ده في جذر المستودع (index.html + manifest.webmanifest + sw.js + فولدرات icons و vendor).
مهم: لازم فولدر icons وفولدر vendor يترفعوا كاملين بنفس الأسماء (حروف صغيرة).

Settings > Pages > Deploy from branch > main > root. الرابط: https://USERNAME.github.io/REPO/

بعد أول فتح أونلاين، التطبيق بيشتغل بدون نت بكل حاجة (الرسم والـ PDF والتصدير).
لو التثبيت مش بيظهر: من داخل التطبيق ← الإعدادات ← "تثبيت كتطبيق" بيفتح فحص بيقولك بالظبط إيه الناقص.

عند أي تحديث غيّر رقم النسخة في sw.js (مثلاً afaq-v10 إلى afaq-v11) مع كل رفعة.
